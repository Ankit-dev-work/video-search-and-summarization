This guide explains how to deploy **AutoMagicCalib (AMC) as a VSS service**. It uses the VSS Docker Compose deployment and pre-built `vss-auto-calibration` and `vss-auto-calibration-ui` containers. It is not the standalone DeepStream `tools/auto-magic-calib` setup.

AMC is a separate VSS microservice and UI. The VSS agent, NIMs, VST, and RTVI services are not required for standalone AMC deployment. The warehouse auto-calibration profile can additionally connect AMC to VIOS/VST for RTSP capture.

## Prerequisites

- x86_64 host running Ubuntu 24.04
- NVIDIA GPU with NVENC hardware encoding
- NVIDIA Driver 590 or newer
- Docker configured for non-root use
- NVIDIA Container Toolkit
- NGC CLI and an NGC API key with access to the AMC image namespace
- A checkout of the [VSS repository](https://github.com/NVIDIA-AI-Blueprints/video-search-and-summarization)

AMC calibration requires a supported x86_64 NVIDIA GPU host. If calibration is not being run on this host, use an existing calibration artifact or run calibration on a supported host and transfer the result.

## VSS Deployment

The VSS AMC deployment is managed from `deploy/docker` and uses the Warehouse Operations environment layers:

- `industry-profiles/warehouse-operations/.env` — checked-in service defaults
- `industry-profiles/warehouse-operations/overrides.env` — runtime override template
- `industry-profiles/warehouse-operations/generated.env` — active host-specific values

Set `VSS_APPS_DIR` to the absolute path of the repository's `deploy/docker` directory. Set `VSS_DATA_DIR` to a separate runtime data directory.

### Initialize the runtime environment

```bash
cd /path/to/video-search-and-summarization/deploy/docker
cp industry-profiles/warehouse-operations/overrides.env \
   industry-profiles/warehouse-operations/generated.env

# Edit generated.env and set these values:
# HOST_IP=<reachable host IP>
# VSS_APPS_DIR=/absolute/path/to/video-search-and-summarization/deploy/docker
# VSS_DATA_DIR=/absolute/path/to/vss-data
# VSS_AUTO_CALIBRATION_HOST_PORT=8010
# VSS_AUTO_CALIBRATION_UI_HOST_PORT=5000
# COMPOSE_PROFILES=vss-auto-calibration,vss-auto-calibration-ui
```

`HOST_IP` must be reachable from the browser. Do not use `localhost` or `0.0.0.0` for this value.

### Authenticate with NGC

```bash
export NGC_CLI_API_KEY=<NGC_CLI_API_KEY>
printenv NGC_CLI_API_KEY | docker login nvcr.io \
  --username '$oauthtoken' --password-stdin
```

Never print or commit the API key.

### Optional VGGT setup

AMC works without VGGT. To enable independent VGGT calibration, download the licensed `vggt_1B_commercial.pt` model and place it at:

```text
${VSS_DATA_DIR}/auto-calib/vggt/vggt_1B_commercial.pt
```

Accept the model license and obtain the model from the [VGGT model page](https://huggingface.co/facebook/VGGT-1B-Commercial) before downloading it.

### Optional RTSP setup

RTSP calibration requires VIOS. If VIOS/VST is part of the same warehouse deployment, the warehouse profile wires `VIOS_BASE_URL` automatically. For an independently deployed VIOS instance, set `VIOS_BASE_URL` in `generated.env` to the reachable VIOS URL and verify it before starting AMC.

### Review and start AMC

```bash
cd /path/to/video-search-and-summarization/deploy/docker

set -a
. industry-profiles/warehouse-operations/.env
. industry-profiles/warehouse-operations/generated.env
set +a

docker compose \
  --env-file industry-profiles/warehouse-operations/.env \
  --env-file industry-profiles/warehouse-operations/generated.env \
  config > resolved.yml

# Review resolved.yml and confirm the AMC services and image references.
docker compose \
  --env-file industry-profiles/warehouse-operations/.env \
  --env-file industry-profiles/warehouse-operations/generated.env \
  up -d
```

For warehouse RTSP auto-calibration, use the warehouse variant instead:

```dotenv
MODE=auto-calibration
BP_PROFILE=bp_wh_auto_calib
COMPOSE_PROFILES=${COMPOSE_PROFILES_WH_AUTO_CALIB}
```

Do not combine the standalone service list with the warehouse profile settings.

### Verify the deployment

```bash
PORT=${VSS_AUTO_CALIBRATION_HOST_PORT:-8010}
UI_PORT=${VSS_AUTO_CALIBRATION_UI_HOST_PORT:-5000}

curl "http://localhost:${PORT}/v1/ready"
curl -I "http://localhost:${UI_PORT}/"
docker ps --filter name=vss-auto-calibration
```

Expected results include a ready AMC response and these containers:

- `vss-auto-calibration`
- `vss-auto-calibration-ui`

Open the UI at:

```text
http://<HOST_IP>:<VSS_AUTO_CALIBRATION_UI_HOST_PORT>
```

### Ensure projects are writable

AMC stores projects under:

```text
${VSS_APPS_DIR}/services/auto-calibration/projects
```

The container runs as UID 1000. On a fresh checkout, ensure this directory is writable by that user before creating a project:

```bash
PROJECTS_DIR="${VSS_APPS_DIR}/services/auto-calibration/projects"
mkdir -p "$PROJECTS_DIR"
sudo setfacl -m u:1000:rwx "$PROJECTS_DIR"
```

Use a scoped ACL rather than `chmod -R 777`.

### Stop AMC

```bash
docker compose \
  --env-file industry-profiles/warehouse-operations/.env \
  --env-file industry-profiles/warehouse-operations/generated.env \
  down
```
